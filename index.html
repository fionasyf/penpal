Penpal — 技术支持

一边打字，一边把外语说地道

关于 Penpal

Penpal 是专为中文用户打造的智能语言输入键盘。支持英语、日语、韩语、粤语、法语、德语、西班牙语等多种语言，在你打字的同时帮你写出更自然、更地道的外语表达。

常见问题

Penpal 需要注册或登录吗？

不需要。Penpal 不收集你的身份信息，下载后即可使用。

为什么需要「完全访问」权限？

Penpal 是键盘扩展，需要网络访问才能将文本发送至云端 AI 进行语法检查和语音转文字。所有数据仅用于实时处理，处理完成后不会保留。

支持哪些语言？

目前支持英语、日语、韩语、粤语、法语、德语、西班牙语。中文作为输入源语言，可随时切换目标语言。

语音输入无法识别？

请检查系统设置中是否已授予 Penpal 麦克风权限。首次使用时需要在键盘工具栏中点击麦克风图标并允许授权。

Penpal 安全吗？

Penpal 不存储可识别你个人身份的信息。详细数据处理方式请参阅隐私政策。

Penpal — Support

Type smarter, speak naturally

About Penpal

Penpal is a smart language input keyboard built for Chinese speakers. It supports English, Japanese, Korean, Cantonese, French, German, Spanish, and more — helping you write more natural and idiomatic expressions as you type.

FAQ

Do I need to sign up or log in?

No. Penpal does not collect your identity information. Download and use it right away.

Why does it require Full Access?

Penpal is a keyboard extension. It needs network access to send text to cloud AI for grammar checking and speech-to-text. All data is processed in real time and is not retained afterwards.

Which languages are supported?

English, Japanese, Korean, Cantonese, French, German, and Spanish. Chinese is the input source language, and you can switch target languages at any time.

Voice input isn't working?

Please check system settings to ensure Penpal has microphone permission. On first use, tap the microphone icon in the keyboard toolbar and grant permission.

Is Penpal safe?

Penpal does not store any information that identifies you personally. For details on data handling, please see our Privacy Policy.
